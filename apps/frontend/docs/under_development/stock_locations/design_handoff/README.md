# Handoff

One folder per interface. Each folder holds the document describing that screen and a `screenshots/` folder for its images.

Pass `00-global/00-global.md` once per session, then one screen folder per screen.

| folder | screen |
|---|---|
| 00-global | shared tokens, states, conventions |
| 01-report-compacted | Stock Report, compacted |
| 02-report-grouped | Stock Report, grouped by location |
| 03-filter-sheet | Filter sheet |
| 04-entry-detail | Entry detail |
| 05-generate-pdf | Generate PDF sheet |
| 06-stock-locations | Stock locations (settings root) |
| 07-location-detail | Location detail |
| 08-new-instance-step1 | New instance, step 1 |
| 09-thresholds | Stock thresholds, step 2 |
| 10-pdf-a4 | A4 PDF report |
